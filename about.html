System Overview

System architecture overview, core objectives, and technical documentation.

1. System Overview

The Traffic Accident Hotspot Mapper is a specialized road safety platform. Traffic accidents represent a critical public safety challenge. By leveraging Geographic Information Systems (GIS) and Artificial Intelligence (AI) analytics, this system assists authorities and the public in identifying high-risk accident hotspots, evaluating risk factors, and formulating evidence-based road safety mitigations.

2. System Objectives

  • Provide a secure, dynamic GIS database to store and manage accident location coordinates (latitude, longitude) using Firebase Firestore.
  • Enable spatial density visualization and interactive hotspot mapping using Leaflet.js to display real-time road accident distributions.
  • Integrate Google Gemini API intelligence to summarize spatio-temporal risk factors, analyze dominant severity patterns, and generate actionable road improvement suggestions.

3. Technology Architecture

Frontend UI Engine

HTML5, Tailwind CSS, Google Fonts, Responsive Media Queries.

Map Rendering & GIS

Leaflet.js, Heatmap Layer, Pulse Markers, Custom Spatial Filtering.

Database & Auth (Cloud Sync)

Firebase Firestore (NoSQL) & Firebase Auth (RBAC Session Guard).

Artificial Intelligence Engine

Node.js Express proxy with Google Gen AI SDK model 'gemini-2.5-flash'.
